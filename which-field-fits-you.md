# Which field fits you?

Not sure where to start? Match what you enjoy to a field, then try its first project before committing. Fields overlap, and you can change direction later because the foundations carry over.

| If you enjoy... | Consider | Try this first |
|---|---|---|
| Teaching computers to learn from data | AI and Machine Learning | Train a simple classifier on a public dataset. |
| Finding patterns, answering questions with data | Data Science and Data Engineering | Analyze a CSV in a notebook and chart one finding. |
| Breaking things to understand how they fail | Cybersecurity | Complete a beginner web security lab, then write up the fix. |
| Designing and building what users see and click | Frontend Development | Build a responsive page and add interactivity with JavaScript. |
| Designing the data, rules and APIs behind an app | Backend Development | Build a small REST API backed by a database. |
| Wanting to build a whole product end to end | Full Stack Development | Build a small app with an interface, an API and a database. |
| Building apps for phones | Mobile Development | Build a one-screen app that stores a list locally. |
| Polished tools that run on a computer | Desktop Development | Build a small notes or timer window app. |
| Making interactive worlds and mechanics | Game Development | Make a playable 2D game with one mechanic. |
| Keeping services running and automating releases | Cloud and DevOps | Containerize an app and add a CI workflow. |
| Low-level control of memory, hardware and timing | Systems and Embedded Development | Write a tiny shell in C, or blink an LED from a board. |
| Understanding how machines communicate | Networking | Capture and inspect a web request in Wireshark. |
| Visuals, 3D, shaders and immersive spaces | Computer Graphics and AR VR | Draw and light a 3D object. |
| Proofs, puzzles and the limits of computation | Theoretical Computer Science | Prove a sorting algorithm correct and time it. |
