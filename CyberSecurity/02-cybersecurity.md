# Cybersecurity

*Understand vulnerabilities, protect systems, and investigate incidents.*

## What this field is

Cybersecurity protects systems, networks, applications and information from unauthorized access, disruption or misuse. It covers preventing weaknesses, detecting suspicious activity and responding to incidents. People in this field review software, test defenses, investigate attacks and design protective controls. Typical outcomes include safer applications, monitored networks, incident reports and recovery plans.

**Learning sequence** 1. Systems and networks → 2. Security fundamentals → 3. Authorized labs → 4. Investigate and report

**Languages** Python, Bash and SQL. Add JavaScript for web security, PowerShell for Windows, and C plus assembly for reverse engineering.

## Learn the essentials

**Foundations** Linux and Windows administration, networking, HTTP, permissions and access control.

**Security** Common vulnerabilities, cryptography fundamentals, threat modeling, secure design, logging and incident response.

## Use these tools

A Linux virtual machine, Wireshark, Nmap, Burp Suite Community Edition and browser developer tools. Practice in explicitly authorized environments such as PortSwigger Academy labs.

## Choose a specialization

| Branch | Additional learning and tools |
|---|---|
| Application security | API testing, web vulnerabilities, code review, Burp Suite and vulnerability reports. |
| Defensive security | Windows Event Logs, Sysmon, a SIEM such as Splunk or Microsoft Sentinel, detection rules and incident investigation. |
| Reverse engineering | C, assembly, executable formats, Ghidra and a debugger. |
| Cloud security | IAM, network controls, audit logs, secrets and configuration security. |
| Cryptography | Number theory, probability, security definitions, protocols and established cryptographic libraries. |

## Add later

Advanced cloud security, malware analysis, detection engineering or deeper cryptographic theory, depending on your branch.

## Project milestone

Investigate a vulnerable lab application, demonstrate a weakness, implement a fix and write a clear report.
