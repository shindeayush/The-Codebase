# Networking

*Design, configure and troubleshoot communication between computers.*

## What this field is

Networking connects devices and services so they can exchange information reliably. It covers how data is addressed, routed, transmitted and controlled across local networks and the internet. Network professionals design connections, configure infrastructure, diagnose failures and plan capacity. Examples include office networks, data center connectivity and links between cloud services.

**Learning sequence** 1. TCP/IP and subnetting → 2. Switching and routing → 3. Services and security → 4. Capture, debug and automate

**Languages** Python and Bash for automation; YAML and JSON for configuration and data exchange.

## Learn the essentials

**Protocols** Ethernet, IPv4/IPv6, subnetting, ARP, TCP/UDP and TCP/IP layering.

**Infrastructure** Switches, routing, VLANs, DNS, DHCP, NAT, firewalls, VPNs and TLS.

**Troubleshooting** Packet captures, routing tables, connectivity failures, latency, throughput and repeatable diagnosis.

## Use these tools

Wireshark, tcpdump, ping, traceroute, dig or nslookup, ip, ss and iperf. Build labs with Packet Tracer or GNS3.

## Choose a specialization

| Path | Focus |
|---|---|
| Network engineering | Subnetting, VLANs, routing, firewalls and simulated labs in Packet Tracer or GNS3. |
| Network automation | Python, YAML and JSON, device and cloud APIs; Ansible later. |
| Traffic analysis | Wireshark, tcpdump, packet captures, latency and throughput diagnosis. |

## Add later

OSPF, BGP, cloud networking, Ansible-based automation and software-defined networking.

## Project milestone

Build a simulated network with multiple subnets, VLANs, routing, DNS and firewall rules. Introduce failures and document how you diagnose them.
