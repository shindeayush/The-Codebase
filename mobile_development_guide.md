# Mobile Development Guide

A curated list of free resources and learning paths for Mobile Development.

## Free Resources & Reference Links

### 1. Flutter Documentation & Labs
Google’s free UI toolkit for building natively compiled cross-platform mobile apps from a single codebase using Dart.
* **Link:** [https://docs.flutter.dev/](https://docs.flutter.dev/)

### 2. Android Developers Documentation
Official guides, Kotlin courses, and Jetpack Compose tutorials for native Android app development.
* **Link:** [https://developer.android.com/](https://developer.android.com/)

### 3. Apple Developer Documentation (Swift / SwiftUI)
Official learning materials, sample code, and tutorials for iOS, iPadOS, and macOS development using SwiftUI.
* **Link:** [https://developer.apple.com/documentation/swiftui](https://developer.apple.com/documentation/swiftui)

### 4. React Native Official Documentation
Framework for building native mobile applications using React and JavaScript/TypeScript.
* **Link:** [https://reactnative.dev/](https://reactnative.dev/)
