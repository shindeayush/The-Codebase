# Desktop Development Guide

A curated list of free resources and learning paths for Desktop Development.

## Free Resources & Reference Links

### 1. Microsoft .NET Desktop Development
Official documentation and tutorials for building native Windows and macOS applications using C#, WPF, and WinUI.
* **Link:** [https://dotnet.microsoft.com/en-us/apps/desktop](https://dotnet.microsoft.com/en-us/apps/desktop)

### 2. Electron Documentation
Popular cross-platform desktop framework using JavaScript, HTML, and CSS (powers VS Code, Slack, Discord).
* **Link:** [https://www.electronjs.org/](https://www.electronjs.org/)

### 3. Tauri Documentation
Modern framework for building lightweight, fast, secure desktop applications using HTML/JS and Rust.
* **Link:** [https://tauri.app/](https://tauri.app/)

### 4. Qt Documentation & Tutorials
Industry-standard C++ framework for cross-platform desktop application development.
* **Link:** [https://doc.qt.io/](https://doc.qt.io/)
