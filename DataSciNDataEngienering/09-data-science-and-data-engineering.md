# Data Science and Data Engineering

*Choose between analyzing data and building the systems that deliver it.*

## What this field is

Data science uses statistics, programming and domain knowledge to answer questions, explain patterns and build predictive models. Data engineering builds the pipelines, storage and processing systems that make trustworthy data available. A data scientist might investigate why sales changed; a data engineer might create the reliable daily dataset used for that investigation.

**Learning sequence** 1. Python and SQL → 2. Clean and model data → 3. Analyze or build pipelines → 4. Validate and communicate

**Languages** Python and SQL for both paths.

## Learn the essentials

**Shared skills** Cleaning, schema design, joins, validation, reproducibility and clear documentation.

**Data science** Statistics, exploratory analysis, hypothesis tests, experiments, regression, visualization and communicating uncertainty.

**Data engineering** Data modeling, ETL/ELT, batch processing, warehouses, orchestration, data quality, partitioning and distributed processing.

## Use these tools

Use the branch-specific stack below; keep pipelines and analyses under version control.

## Choose a specialization

| Branch | Starting tools |
|---|---|
| Data science | JupyterLab, NumPy, pandas, SciPy, scikit-learn, Matplotlib, seaborn, PostgreSQL, Excel and one BI tool such as Power BI. |
| Data engineering | PostgreSQL, Python database clients, pandas, Docker, dbt and one orchestrator such as Airflow. Add PySpark when scale warrants it. |

## Add later

Data science: causal inference, time series, Bayesian methods and advanced ML. Data engineering: Spark, Kafka, a cloud warehouse, streaming, lineage and governance.

## Project milestone

Data science: test a clear hypothesis and explain the evidence and limitations. Data engineering: schedule a validated data pipeline that loads a database and supplies a dashboard.
