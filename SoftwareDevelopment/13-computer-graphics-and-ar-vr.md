# Computer Graphics and AR VR

*Generate images or build applications that interact with three-dimensional space.*

## What this field is

Computer graphics develops methods for generating and displaying images, animation and three-dimensional scenes. Augmented reality overlays digital content on a view of the physical world; virtual reality presents an immersive simulated environment. Work includes rendering, tracking, spatial interaction and performance. Applications include visualization, design tools, training simulations, games and interactive experiences.

**Learning sequence** 1. Vectors and transforms → 2. Rendering or engine basics → 3. Shaders or XR interaction → 4. Profile and test

**Languages** C++ for graphics programming; C# for a Unity AR/VR path; GLSL or HLSL for shaders.

## Learn the essentials

**Mathematics** Vectors, matrices, coordinate systems, transforms, projections, quaternions and geometry.

**Graphics** Rendering pipeline, meshes, textures, lighting, cameras, shaders, rasterization and animation.

**AR and VR** Tracking, spatial input, interaction design, frame timing, comfort, OpenXR and platform-specific AR tools as needed.

## Use these tools

Blender and a graphics debugger such as RenderDoc. Choose Unity or Unreal for interactive applications.

## Choose a specialization

| Path | Suggested learning sequence |
|---|---|
| Graphics programming | C++ to basic OpenGL to shaders to a small renderer. |
| AR and VR applications | C# to Unity to 3D interactions to OpenXR to device testing. |

## Add later

Physically based rendering, ray tracing, GPU compute, Vulkan or Direct3D 12.

## Project milestone

Build a small renderer with textured objects and lighting, or a device-tested VR room with object interaction.
