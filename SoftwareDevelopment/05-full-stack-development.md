# Full Stack Development

*Build complete web applications from interface to database to deployment.*

## What this field is

Full stack development combines frontend and backend work and connects them into a complete application. A full stack developer works comfortably on both sides, usually with more depth on one, and owns integration, deployment and the quality of the whole product. Examples include online shops, booking systems, dashboards and collaboration tools.

**Learning sequence** 1. Frontend basics → 2. Backend and database → 3. Connect and secure → 4. Deploy and maintain

**Languages** TypeScript on both sides; SQL for databases.

## Learn the essentials

**Prerequisites** Work through the Frontend and Backend essentials at a working level first.

**Integration** API contracts, shared types, CORS, authentication flows and validation on both sides.

**Delivery** Environment configuration, production builds, HTTPS, logs, Docker basics and CI.

## Use these tools

Everything from the Frontend and Backend paths, plus Docker Compose and GitHub Actions. Optionally use Next.js to combine both sides in one project.

## Choose a specialization

| Path | Focus |
|---|---|
| Frontend-leaning | Richer interfaces and design systems, with a lean API behind them. |
| Backend-leaning | Strong API and database design, with a simpler interface. |
| Product-focused | End-to-end features: accounts, payments, deployment and iteration. |

## Add later

Next.js, Redis caching, background jobs, queues, WebSockets, monitoring and system design.

## Project milestone

Deploy a task manager with accounts, role-based permissions, database storage, input validation and automated tests.
