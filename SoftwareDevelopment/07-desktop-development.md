# Desktop Development

*Build installable applications with a responsive graphical interface.*

## What this field is

Desktop development creates applications that run on a computer's operating system, usually through an installed program. These applications can work with local files, connected hardware and background tasks, and may also use online services. Typical products include code editors, media tools, accounting software and scientific applications. Work includes building the interface, integrating system features and distributing updates.

**Learning sequence** 1. Choose a platform → 2. Events and interface → 3. Files, data and tasks → 4. Package and release

**Languages** C# for a Windows .NET path; TypeScript for Electron; C++ for Qt; Python for PySide6.

## Learn the essentials

**Interface** Event-driven programming, layouts, application state, navigation and accessibility.

**Application behavior** Files, SQLite, background work, concurrency and keeping the interface responsive.

**Distribution** OS integration, settings, testing, packaging, installers and updates.

## Use these tools

The IDE and framework for your chosen stack, a debugger, a profiler, a GUI designer where available and packaging tools.

## Choose a specialization

| Goal | Starting stack |
|---|---|
| Windows applications | C# + .NET + WPF; Visual Studio. |
| Web skills across platforms | TypeScript + Electron; Node.js tooling and VS Code. |
| Native cross-platform | C++ + Qt; Qt Creator and CMake. |
| Python utilities | Python + PySide6; Qt Designer and a packaging tool such as PyInstaller. |

## Add later

Code signing, crash reporting, richer OS integration and performance tuning.

## Project milestone

Build a notes application with search, local database storage, import/export and an installer.
