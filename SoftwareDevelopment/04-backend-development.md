# Backend Development

*Build the servers, APIs and databases that power applications.*

## What this field is

Backend development builds the server-side logic that stores data, enforces rules and exposes APIs to clients. It covers authentication, authorization, databases, background work and reliability. Backend developers focus on correctness, security and performance under load. Examples include payment APIs, booking logic, account systems and notification services.

**Learning sequence** 1. Server language and HTTP → 2. APIs and authentication → 3. Databases and SQL → 4. Test and deploy

**Languages** TypeScript on Node.js, or another server language such as Python, Go, Java or C#; choose one. SQL for databases.

## Learn the essentials

**Server basics** HTTP, routing, middleware, validation, error handling and logging.

**APIs and security** REST design, authentication, authorization, password handling, rate limiting and secrets.

**Database** PostgreSQL schema design, keys, joins, indexes, transactions and migrations.

**Reliability** Automated tests, configuration, environment variables and basic observability.

## Use these tools

Node.js with Express, PostgreSQL, npm, curl or Postman, Git and GitHub. Test with Vitest or Jest and Supertest. Deploy with production configuration, HTTPS, logs and Docker basics.

## Choose a specialization

| Path | Focus |
|---|---|
| API services | REST design, validation, versioning and OpenAPI documentation. |
| Data and persistence | Schema design, query tuning, indexing, transactions and migrations. |
| Reliability and scale | Caching, queues, background jobs, monitoring and failure handling. |
