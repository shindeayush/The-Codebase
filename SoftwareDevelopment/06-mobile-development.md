# Mobile Development

*Build applications for phones and tablets. Start with one platform or framework.*

## What this field is

Mobile development creates applications for phones and tablets. It combines interface design and application logic with device capabilities such as cameras, location, notifications and local storage. Developers account for touch interaction, battery use, unreliable connections and platform rules. They build products such as navigation tools, messaging applications, fitness trackers and mobile banking interfaces.

**Learning sequence** 1. Choose one platform → 2. Layouts and navigation → 3. Data, APIs and storage → 4. Test and release

**Languages** Kotlin for Android, Swift for iOS, Dart for Flutter, or TypeScript for React Native. Choose one.

## Learn the essentials

**Application basics** Layouts, navigation, state management, asynchronous work, APIs and local storage.

**Platform behavior** Authentication, permissions, lifecycle, offline behavior, accessibility and background limits.

**Delivery** Automated tests, device testing, release signing and store submission basics.

## Use these tools

Use the SDK, emulator or simulator, debugger and profiler for your chosen platform.

## Choose a specialization

| Path | Language and tools |
|---|---|
| Android | Kotlin, Jetpack Compose, Android Studio, Android SDK and emulator. |
| iOS | Swift, SwiftUI, Xcode and iOS Simulator. A Mac is needed for the standard native workflow. |
| Flutter | Dart, Flutter SDK, Android Studio or VS Code; platform build tools as needed. |
| React Native | TypeScript, React Native, Expo and Android/iOS development tools. |

## Add later

Push notifications, background tasks, deep links, performance tuning and platform-specific integrations.
