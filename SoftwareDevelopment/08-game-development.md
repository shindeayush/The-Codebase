# Game Development

*Create interactive games and finish small playable releases.*

## What this field is

Game development turns rules, interaction, art and sound into playable experiences. Programming work implements gameplay, movement, physics, game AI, interfaces and the systems that keep the experience running smoothly. Developers work with designers and artists to build, test and refine games. Projects range from small puzzles and mobile games to large multiplayer worlds.

**Learning sequence** 1. Choose an engine → 2. Input, scenes and math → 3. Gameplay and assets → 4. Profile and export

**Languages** GDScript for Godot, C# for Unity, or Blueprints followed by C++ for Unreal Engine.

## Learn the essentials

**Game foundations** Game loops, input, scenes/entities, vectors, transforms, collisions, physics and cameras.

**Complete experience** Animation, audio, UI, saving/loading, level flow and player feedback.

**Engineering** Debugging, gameplay testing, profiling, asset management and version control.

## Use these tools

Your chosen engine editor and profiler, Git, Blender for 3D assets and an image editor for 2D assets.

## Choose a specialization

| Engine | Suggested starting direction |
|---|---|
| Godot | GDScript and a small 2D game. |
| Unity | C# and a small 2D or 3D game. |
| Unreal Engine | Blueprints, then C++, for a small 3D game. |

## Add later

Shaders, procedural generation, game AI, multiplayer networking and optimization.

## Project milestone

Finish a small game with a start menu, sound, saving, restart behavior and a downloadable build.
