# Frontend Development

*Build the browser interfaces people see, click and rely on.*

## What this field is

Frontend development builds the part of a website or web application that people see and interact with in the browser. It covers layout, styling, interaction, forms and the display of data from servers. Frontend developers focus on usability, accessibility and performance across devices and browsers. Examples include storefronts, dashboards, booking interfaces and online editors.

**Learning sequence** 1. HTML, CSS and accessibility → 2. JavaScript and the DOM → 3. TypeScript and React → 4. Test and deploy

**Languages** HTML and CSS for structure and presentation; JavaScript, then TypeScript.

## Learn the essentials

**Web foundations** Semantic HTML, responsive layouts, accessibility, forms, HTTP and browser developer tools.

**JavaScript** DOM, events, modules, async JavaScript, fetch and error handling.

**React** Components, props, state, hooks, routing, and loading and error states.

**Quality** Performance basics, cross-browser behavior and frontend testing.

## Use these tools

VS Code, browser developer tools, npm, Vite, Git and GitHub. Test with Vitest, React Testing Library and Playwright. Deploy a production build to a static host.

## Choose a specialization

| Path | Focus |
|---|---|
| Application frontend | React and TypeScript applications: state, routing, forms and data fetching. |
| Design systems and accessibility | Reusable components, keyboard and screen reader support, and visual consistency. |
| Performance and web platform | Core Web Vitals, bundling, caching, browser APIs and profiling. |

## Add later

Next.js, state management libraries, animation, Web Components and advanced performance tuning.

## Project milestone

Build and deploy a responsive, accessible task manager interface that calls an API, handles loading and error states, and has automated tests.
