# Cloud Computing Guide

A curated list of free resources and learning paths for Cloud Computing.

## Free Resources & Reference Links

### 1. IITK Cloud Computing Roadmap & Guides
Overview of cloud services, storage, networking basics, and cloud deployment models.
* **Link:** [https://www.eicta.iitk.ac.in/knowledge-hub/cloud-computing/cloud-computing-roadmap-2026](https://www.eicta.iitk.ac.in/knowledge-hub/cloud-computing/cloud-computing-roadmap-2026)

### 2. AWS Cloud Practitioner Free Training
Official beginner-friendly cloud modules and self-paced digital courses from Amazon Web Services.
* **Link:** [https://skillbuilder.aws/](https://skillbuilder.aws/)

### 3. Microsoft Learn for Azure
Free interactive learning paths for fundamentals, architecture, and administration on Microsoft Azure.
* **Link:** [https://learn.microsoft.com/en-us/training/azure/](https://learn.microsoft.com/en-us/training/azure/)

### 4. Google Cloud Skills Boost - Free Tier Labs
Self-paced hands-on labs and introductory courses for Google Cloud Platform.
* **Link:** [https://www.cloudskillsboost.google/](https://www.cloudskillsboost.google/)
