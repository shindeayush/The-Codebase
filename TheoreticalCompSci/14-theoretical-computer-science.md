# Theoretical Computer Science

*Study what can be computed and how efficiently problems can be solved.*

## What this field is

Theoretical computer science studies the mathematical principles and limits of computation. It asks which problems computers can solve, how much time or memory solutions require, and how to prove an algorithm correct. Work often produces proofs, algorithms and complexity results. These ideas help explain why some problems have efficient solutions while others remain computationally difficult.

**Learning sequence** 1. Logic and proofs → 2. Algorithms and analysis → 3. Automata and computability → 4. Complexity and research

**Languages** Python for experiments; C++ for algorithm implementations. A functional language is optional.

## Learn the essentials

**Mathematics** Logic, sets, relations, combinatorics, graph theory, probability, induction, contradiction and other proof techniques.

**Algorithms** Correctness proofs, asymptotic analysis, divide and conquer, greedy methods, dynamic programming and graph algorithms.

**Computation** Automata, formal languages, Turing machines, decidability and reductions.

**Complexity** P, NP, NP-completeness, tractability, approximation and randomized algorithms.

## Use these tools

A code editor, language runtime, test framework and LaTeX for mathematical writing.

## Choose a specialization

| Path | Focus |
|---|---|
| Algorithms | Correctness proofs, asymptotic analysis, design paradigms and C++ implementations. |
| Computability and complexity | Automata, Turing machines, decidability, reductions and NP-completeness. |
| Logic and formal methods | Proof techniques, formal logic, and Lean or Rocq for machine-checked proofs. |

## Add later

Lean or Rocq for formal proofs; specialized topics such as computational geometry or cryptographic theory.

## Project milestone

Implement several algorithms, prove correctness, analyze time and space complexity, and compare measured performance with theoretical predictions.
