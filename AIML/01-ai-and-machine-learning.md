# AI and Machine Learning

*Build systems that learn patterns, make predictions, or generate content.*

## What this field is

Artificial intelligence develops systems that perform tasks such as recognizing images, understanding language, planning and making decisions. Machine learning is a branch of AI in which models learn patterns from data rather than relying only on hand-written rules. Work includes preparing data, training and evaluating models, and building applications such as recommendation systems, fraud detectors and language assistants.

**Learning sequence** 1. Python and math → 2. Prepare data → 3. Train and evaluate → 4. Serve and monitor

**Languages** Python first; SQL for retrieving and preparing data.

## Learn the essentials

**Mathematics** Linear algebra, probability, statistics, derivatives, gradients and optimization.

**Machine learning** Cleaning, exploratory analysis, regression, classification, clustering, feature engineering, train/validation/test splits, cross-validation, metrics, overfitting and data leakage.

## Use these tools

JupyterLab, virtual environments, NumPy, pandas, Matplotlib and scikit-learn. Then PyTorch. Use pytest, FastAPI and Docker to test and serve models.

## Choose a specialization

| Branch | Additional learning |
|---|---|
| Generative AI and NLP | Tokenization, embeddings, transformers, Hugging Face Transformers, model APIs, retrieval-augmented generation, evaluation and fine-tuning. |
| Computer vision | Image processing, OpenCV, convolutional networks, vision transformers, detection and segmentation. |
| Robotics | C++, ROS 2, coordinate transforms, sensors, control theory, localization, motion planning and simulation. |

## Add later

MLflow for experiment tracking, model monitoring, distributed training and GPU optimization.

## Project milestone

Train on real data, compare with a simple baseline, document evaluation and limitations, and publish a tested prediction API.
