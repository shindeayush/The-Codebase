# Cloud and DevOps

*Deploy applications reliably and automate the infrastructure that runs them.*

## What this field is

Cloud computing runs applications and infrastructure on remotely provided computing services. DevOps brings development and operations together through collaboration, automation and continuous feedback. Work includes provisioning infrastructure, automating releases, monitoring services and recovering from failures. Related site reliability engineering applies software engineering methods to availability and operational work. These practices support products that must remain dependable as usage grows.

**Learning sequence** 1. Linux and networking → 2. Deploy and containerize → 3. CI/CD and one cloud → 4. Automate and observe

**Languages** Bash and Python; YAML for configuration; HCL for Terraform. Add PowerShell for Windows work.

## Learn the essentials

**Foundations** Linux administration, DNS, TLS, networking, processes, permissions, storage and application deployment.

**Cloud** Choose AWS, Azure or Google Cloud. Learn IAM, virtual networks, compute, object storage, managed databases and load balancers.

**Operations** Logs, metrics, traces, alerts, secrets, backups, recovery and cost management.

## Use these tools

Docker images, containers, volumes, networks and Compose. GitHub Actions for CI/CD. Terraform for infrastructure. Then a monitoring stack such as Prometheus and Grafana.

## Choose a specialization

| Path | Focus |
|---|---|
| Cloud engineering | Provider services, IAM, virtual networks, managed databases, storage and cost management. |
| DevOps and platform | CI/CD with GitHub Actions, containers, Terraform, release automation and developer tooling. |
| Site reliability | Monitoring, service objectives, incident response, capacity planning and recovery testing. |

## Add later

Kubernetes and Helm after containers and deployments; configuration management, advanced release strategies and site reliability engineering. Learn service objectives, incident response and reliability tradeoffs.

## Project milestone

Deploy an application with automated tests and releases, versioned infrastructure, monitoring and a tested recovery procedure.
