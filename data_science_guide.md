# Data Science Guide

A curated list of free resources and learning paths for Data Science.

## Free Resources & Reference Links

### 1. Coddy Data Science Roadmap
Free browser-based track covering Python, SQL, data manipulation, statistics, and machine learning.
* **Link:** [https://coddy.tech/landing/data-science](https://coddy.tech/landing/data-science)

### 2. Kaggle Courses
Free micro-courses on data analysis, pandas, data visualization, feature engineering, and machine learning.
* **Link:** [https://www.kaggle.com/learn](https://www.kaggle.com/learn)

### 3. Python Data Science Handbook (Jake VanderPlas)
Free digital book covering NumPy, Pandas, Matplotlib, Seaborn, and Scikit-Learn.
* **Link:** [https://jakevdp.github.io/PythonDataScienceHandbook/](https://jakevdp.github.io/PythonDataScienceHandbook/)

### 4. Harvard CS109 Data Science Course Material
Openly available lecture slides, labs, and assignments from Harvard's introduction to data science.
* **Link:** [https://harvard-iacs.github.io/2019-CS109A/](https://harvard-iacs.github.io/2019-CS109A/)
