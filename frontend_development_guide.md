# Frontend Development Guide

A curated list of free resources and learning paths for Frontend Development.

## Free Resources & Reference Links

### 1. The Complete Front-End Roadmap (GitHub)
Free tutorials and docs for HTML, CSS, JavaScript, TypeScript, and modern frameworks like React and Vue.
* **Link:** [https://github.com/harish303118/front-end-roadmap](https://github.com/harish303118/front-end-roadmap)

### 2. MDN Web Docs
The gold standard reference and tutorial site for Web APIs, HTML5, CSS3, and modern JavaScript.
* **Link:** [https://developer.mozilla.org/](https://developer.mozilla.org/)

### 3. Web.dev by Google
In-depth guides on modern web development practices, accessibility, performance, and responsive UI.
* **Link:** [https://web.dev/](https://web.dev/)

### 4. Frontend Mentor
Free practice challenges for building real-world landing pages and components with HTML/CSS/JS code reviews.
* **Link:** [https://www.frontendmentor.io/](https://www.frontendmentor.io/)
