# Backend Development Guide

A curated list of free resources and learning paths for Backend Development.

## Free Resources & Reference Links

### 1. Coddy Backend Path
Free interactive lessons covering server-side languages, SQL, Linux, Git, and Docker.
* **Link:** [https://coddy.tech/landing/backend](https://coddy.tech/landing/backend)

### 2. The Modern JavaScript Tutorial
Comprehensive guide covering backend concepts with Node.js, asynchronous code, and HTTP servers.
* **Link:** [https://javascript.info/](https://javascript.info/)

### 3. Roadmap.sh - Backend Developer
An interactive roadmap detailing skills, technologies, and architecture patterns for backend engineering.
* **Link:** [https://roadmap.sh/backend](https://roadmap.sh/backend)

### 4. Node.js Official Documentation & Guides
Official tutorials, API documentation, and security best practices for Node.js development.
* **Link:** [https://nodejs.org/en/docs/guides/](https://nodejs.org/en/docs/guides/)
