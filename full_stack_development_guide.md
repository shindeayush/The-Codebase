# Full Stack Development Guide

A curated list of free resources and learning paths for Full Stack Development.

## Free Resources & Reference Links

### 1. Full Stack Roadmap (GitHub)
Curated guide detailing frontend, backend, databases, system design, authentication, and security.
* **Link:** [https://github.com/mesbaulislamrony/fullstack-roadmap](https://github.com/mesbaulislamrony/fullstack-roadmap)

### 2. freeCodeCamp
Free certification programs covering Responsive Web Design, JavaScript Algorithms, and Relational Databases.
* **Link:** [https://www.freecodecamp.org/](https://www.freecodecamp.org/)

### 3. The Odin Project
100% free, open-source full stack curriculum covering HTML, CSS, JavaScript, Node.js, and React/Ruby on Rails.
* **Link:** [https://www.theodinproject.com/](https://www.theodinproject.com/)

### 4. Full Stack Open (University of Helsinki)
Deep dive into modern web development with React, Redux, Node.js, MongoDB, GraphQL, and TypeScript.
* **Link:** [https://fullstackopen.com/en/](https://fullstackopen.com/en/)
