# Cybersecurity Guide

A curated list of free resources and learning paths for Cybersecurity.

## Free Resources & Reference Links

### 1. Cyber Security Roadmap (GitHub)
100% free video tutorials and documentation covering IT foundations, network security, and ethical hacking.
* **Link:** [https://github.com/harish303118/cyber-security-roadmap](https://github.com/harish303118/cyber-security-roadmap)

### 2. TryHackMe / HackTheBox
Hands-on free labs, capture-the-flag (CTF) challenges, and interactive rooms for learning cybersecurity.
* **Link:** [https://tryhackme.com/](https://tryhackme.com/)

### 3. PortSwigger Web Security Academy
Free online training for web application security, SQL injection, XSS, and vulnerability exploitation.
* **Link:** [https://portswigger.net/web-security](https://portswigger.net/web-security)

### 4. Cybrary Free Cybersecurity Courses
Fundamentals of ethical hacking, SOC analysis, systems administration, and security standards.
* **Link:** [https://www.cybrary.it/](https://www.cybrary.it/)
