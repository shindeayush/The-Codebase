# Machine Learning Guide

A curated list of free resources and learning paths for Machine Learning.

## Free Resources & Reference Links

### 1. Andrej Karpathy's Neural Networks: Zero to Hero
Free video course on building micrograd, language models, and deep neural networks from scratch in Python.
* **Link:** [https://www.youtube.com/@AndrejKarpathy](https://www.youtube.com/@AndrejKarpathy)

### 2. Scikit-Learn Tutorials & User Guide
Comprehensive documentation and practical machine learning code examples for classification, regression, and clustering.
* **Link:** [https://scikit-learn.org/stable/tutorial/index.html](https://scikit-learn.org/stable/tutorial/index.html)
* **Link:** [https://github.com/gmonce/scikit-learn-book](https://github.com/gmonce/scikit-learn-book)

### 3. Stanford CS229: Machine Learning
Free open lecture notes, video recordings, and problem sets from Stanford's premier ML course.
* **Link:** [https://cs229.stanford.edu/](https://cs229.stanford.edu/)

### 4. Google Machine Learning Crash Course
Free 15-hour self-study course with interactive exercises and TensorFlow video tutorials.
* **Link:** [https://developers.google.com/machine-learning/crash-course](https://developers.google.com/machine-learning/crash-course)
