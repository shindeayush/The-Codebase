# Game Development Guide

A curated list of free resources and learning paths for Game Development.

## Free Resources & Reference Links

### 1. Game Developer Roadmap
Free structured syllabus covering client-side game logic, game engines, physics, rendering, and shaders.
* **Link:** [https://learning.bibha.ai/roadmaps/game-developer](https://learning.bibha.ai/roadmaps/game-developer)

### 2. Godot Engine Docs & Official Tutorials
Free, open-source 2D and 3D game engine documentation with built-in step-by-step guides.
* **Link:** [https://docs.godotengine.org/](https://docs.godotengine.org/)

### 3. Unity Learn (Free Tier)
Official interactive tutorials, sample projects, and learning pathways for 2D, 3D, and AR/VR games.
* **Link:** [https://learn.unity.com/](https://learn.unity.com/)
* **Link:** [https://github.com/StefanoCecere/awesome-opensource-unity](https://github.com/StefanoCecere/awesome-opensource-unity)

### 4. Unreal Engine Online Learning
Free courses, documentation, and starter templates for C++ and Blueprint visual scripting in Unreal Engine 5.
* **Link:** [https://dev.epicgames.com/community/learning](https://dev.epicgames.com/community/learning)
* **Link:** [https://www.classcentral.com/course/freecodecamp-unreal-engine-5-full-course-for-beginners-121115](https://www.classcentral.com/course/freecodecamp-unreal-engine-5-full-course-for-beginners-121115)
