# DevOps Guide

A curated list of free resources and learning paths for DevOps.

## Free Resources & Reference Links

### 1. DevOps Roadmap (GitHub by Milan Milanović)
Comprehensive learning resources covering Git, Linux, Docker, CI/CD, Terraform, and Cloud infrastructure.
* **Link:** [https://github.com/milanm/DevOps-Roadmap](https://github.com/milanm/DevOps-Roadmap)

### 2. Piyush Sachdeva DevOps Roadmap
Step-by-step curriculum with free video playlists for containers, Kubernetes, Ansible, and Monitoring.
* **Link:** [https://github.com/piyushsachdeva/DevOps-Roadmap](https://github.com/piyushsachdeva/DevOps-Roadmap)

### 3. Docker Official Curriculum & Docs
Official guides and hands-on exercises for containerization and microservices architecture.
* **Link:** [https://docs.docker.com/get-started/](https://docs.docker.com/get-started/)

### 4. Kubernetes Basics Interactive Tutorials
Free interactive tutorials provided by CNCF and Kubernetes for deploying and managing container clusters.
* **Link:** [https://kubernetes.io/docs/tutorials/kubernetes-basics/](https://kubernetes.io/docs/tutorials/kubernetes-basics/)
